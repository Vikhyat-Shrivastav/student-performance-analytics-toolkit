# Student Performance Analytics Toolkit

## Project Overview

The Student Performance Analytics Toolkit is a Python-based command-line application designed to manage student records and analyze academic performance.

The program stores student details and marks, calculates total marks and averages, assigns grades, identifies high-performing students, and generates class performance summaries.

It uses Python user-defined functions and functional programming concepts to make the program reusable and organized.

## Features

- Add and validate student records.
- Calculate total marks.
- Calculate average marks.
- Assign grades automatically.
- Generate individual student reports.
- Identify high-performing students.
- Calculate class average.
- Use flexible function arguments.
- Perform data transformation using map().
- Filter records using filter().
- Use lambda expressions.
- Demonstrate recursion.
- Understand local and global variable scope.

## How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd student-performance-analytics-toolkit
```

3. Run the Python program:

```bash
python main.py
```
